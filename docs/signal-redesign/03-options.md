# Options

## A — Quiet Briefing Ledger
Operational one-column sequence with a transient evidence dialog and a compact context rail.

## B — Editorial Morning Brief
Continuous reading column with a dateline, lead sentence, footnote-like proof action, and authored editions.

## C — Signal Lens
Desktop claim-and-proof split with explicit selection; mobile collapses to a linear brief.

All options receive the same view DTO. Their DOM, reading order, and evidence interaction remain structurally different.
